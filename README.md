# Wendy’s Signal-to-Offer Engine 🍔

This project demonstrates a **multi-agent AI system** that converts fragmented
market signals into **launch-ready Wendy’s offers**.

## What It Does
- Detects competitor whitespace
- Analyzes customer behavior
- Identifies when & why trends matter
- Designs differentiated offers
- Produces an executive-ready prioritization scorecard

## Tech Stack
- LangGraph (Agent Orchestration)
- OpenAI / Gemini
- Streamlit (UI)
- GitHub + Streamlit Community Cloud
